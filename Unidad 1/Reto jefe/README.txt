# IA
He preguntado a gemini por prototipos para mi pagina web a partir de un prompt describiendo el tipo de página que quería, esto me viene bien para no tener que programaar a ciegar y seguir un modelo de web

## Promt
Estoy haciendo un whack-a-mole de temática minecraft, y quiero que me ayudes a hacer el diseño de la pagina. Quiero que me generes imagenes prototipo de como podría ser la página. Algunas de las cosas que quiero que tenga sea:
- El tablero del whack-a-mole sea los slots del inventario de minecraft
- El puntero sea el mazo de minecraft
- Lo que aparezca en los slots para pegar sea un bloque de TNT de minecraft

El resto te doy libre imaginacion para que hagas prototipos de paginas web
