# Ready... GO!

Misión M1 · El Despertar del DOM — Web Development I.

## Cómo probarlo
Abre index.html en el navegador (o con Live Server). Pulsa «Ready...»:
aparecerá en algun momento «PARAR!» y verás la puntuacón que has 
conseguido. Tecla secreta: pulsa "i" para el modo oscuro.

## Uso de IA
Use chatgpt como pareja de programación.
Ejemplo de prompt: "Como desabilitar un botón en js?" o "Haz una revisión 
en busca de faltas en mi codigo".
Verifiqué cada cambio jugando una partida completa antes de aceptar la
siguiente fase, y probé los casos límite.
Escribí a mano todo el codigo ayudado por la inteligencia artificual
en bugs, ayudas para quitar y poner etiquetas, y usar Date

## Autopsia
1. Pensar como modularé mi codigo y si usar etiquetas para diferenciar el estado en el que se encuentra el juego
2. El uso de clases y etiquetas data-... puesto que no hay mucha 
diferencia y ambos podrían hacer el mismo funcionamiento
3. Decidir como imprimir el historial
